# Rishita Bhardwaj – portfolio prototype

Static HTML, CSS and JavaScript. No build step.

## Pages
- `index.html` – illustrated desk landing page (every object is a link)
- `home.html` – Home
- `about.html` – About & Career
- `works.html` – Works (7 projects)
- `happy-faces.html` – Happy Faces Foundation case study (linked from Works)
- `workshops.html` – Workshops & Creatives

## Publish on GitHub Pages
1. Create a repository and upload everything in this folder (keep `index.html` at the top level and the `assets` folder beside it).
2. Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
3. After a minute the site is live at `https://<username>.github.io/<repository>/`.

## Add your case-study links
Happy Faces is already linked. Open `assets/js/site.js` and paste the other URLs into the `LINKS` list at the top. Until a link is added, the button shows a small "not added yet" message.
